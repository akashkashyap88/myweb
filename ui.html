* Graphic User Interface

The most widely used type of UI in use today is the Graphic User Interface (GUI). It accepts input through the keyboard, mouse and display the output on the user’s computer screens. The action in a GUI usually performed through direct manipulation of the graphical elements.

The most common elements of a GUI include:

  1. Window
  2. Icon
  3. Menu
  4. Cursor pointer

Process of User Interface Design*

  1. Interface analysis.
  2. Interface design.
  3. Interface construction.
  4. Interface implementation.
  5. Interface validation.
**Interface Analysis** - This is like studying how things are laid out and work on a website or an app. - We look at what are these (like buttons, menus, text books) - Where they are placed, and how they function. - It’s a something like taking apart a toy to see how it’s made and how it works, but with website and apps instead. **Interface Design** - We decide how the interface will look and work based on what we learned during analysis.
